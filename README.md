# Кадр — конструктор промптов для изображений

Готовый статический сайт для преподавателей языков. Формирует промпт на русском языке, который можно вставить в ChatGPT или другой генератор изображений. Сам сайт не обращается к ИИ и не генерирует картинки.

## Как пользоваться

1. Выберите изучаемый язык, уровень и возраст.
2. Введите тему. При необходимости добавьте лексику и грамматику.
3. Выберите один из 30 универсальных форматов, стиль и пропорции.
4. Нажмите «Копировать промпт» и вставьте его в генератор изображений.

Готовый промпт требует только изображение: без текста, вопросов, инструкций или заданий для учеников. Лексика передаётся через предметы, действия и отношения; грамматика — через визуальные ситуации. Все форматы допускают собственную тему. Описание нужного изображения зависит от выбранного уровня, возраста, формата и введённых данных. Конструктор собирает промпт по шаблонам, а интерпретацию темы и рисование выполняет выбранный вами ИИ.

Изучаемый язык не меняет язык интерфейса или промпта: оба остаются русскими. Он задаёт контекст для интерпретации лексики. Любой язык можно ввести через пункт «Другой язык».

## Открыть на компьютере

Распакуйте ZIP полностью и откройте `index.html` в браузере. Все четыре файла сайта должны оставаться рядом: `index.html`, `styles.css`, `formats.js`, `app.js`. Интернет для конструктора не требуется. Если браузер не разрешает автоматическое копирование, текст выделится: нажмите Ctrl+C или ⌘C.

## Разместить на GitHub Pages

1. Создайте репозиторий GitHub. Для бесплатного GitHub Pages используйте публичный репозиторий.
2. Распакуйте ZIP. Загрузите **содержимое архива**, а не сам ZIP, в корень репозитория. Файл `index.html` должен лежать сразу в корне, не во вложенной папке.
3. Сохраните файлы в ветку `main`.
4. Откройте **Settings → Pages**.
5. В **Build and deployment → Source** выберите **Deploy from a branch**.
6. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
7. Дождитесь завершения публикации. Ссылка на сайт появится на странице Pages.

Сборка, Node.js, платный сервер и API-ключи не нужны. Все пути относительные: сайт подходит и для адреса вида `имя.github.io/название-репозитория/`.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Что входит

- 30 форматов в пяти группах; каталог раскрывается кнопкой «Посмотреть все 30 форматов».
- 12 языков в списке и ввод любого другого.
- 7 уровней от Pre-A1 до C2, 5 возрастных групп.
- 6 визуальных стилей и 4 соотношения сторон.
- Автоматическое обновление и копирование промпта.
- Адаптивная версия для телефона и компьютера.

Ввод обрабатывается только в текущей вкладке. Данные не отправляются на сервер и не сохраняются после перезагрузки. Нет аналитики, внешних шрифтов или подключаемых библиотек. При желании сохраните готовый промпт перед закрытием страницы.

Генераторы изображений могут неточно соблюдать количество предметов, отличий и постоянство персонажей. Проверьте полученную картинку перед занятием.

## Изменить сайт

- `index.html` — интерфейс и варианты настроек.
- `styles.css` — оформление.
- `formats.js` — названия и базовые описания 30 форматов.
- `app.js` — сборка промптов, дополнительные требования к форматам и копирование.

После изменения файлов загрузите их в тот же репозиторий: GitHub Pages обновит сайт после публикации.
